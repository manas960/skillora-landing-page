# Skillora — Responsive Product Landing Page

A responsive landing page concept for **Skillora**, a fictional online learning platform. This project is made for a UI/UX design assignment and demonstrates a polished education-platform layout in HTML, CSS, and JavaScript.

## Target audience
College students, beginners learning technology, and early-career professionals looking to gain practical skills.

## Design choices
- Purple and white visual identity communicates creativity and modern learning.
- Inter typography creates a clean, readable hierarchy.
- Sections are arranged to guide visitors from the hero message to features, courses, testimonials, and the final call to action.
- Responsive CSS adapts the navigation, hero, cards, statistics, and footer for smaller screens.

## Features
- Desktop and mobile responsive layouts
- Navigation menu with mobile toggle
- Hero area, platform statistics, feature cards, popular course cards
- Student testimonial cards
- Call-to-action banner and footer newsletter demo
- CSS hover states and smooth section scrolling

## Tech used
HTML5, CSS3, vanilla JavaScript, Google Fonts (Inter).

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a browser.
3. For local development, you can use the VS Code Live Server extension.
